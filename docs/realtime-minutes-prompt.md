# リアルタイム議事録を agent に書かせる指示文

talk-catcher は録音中、区切りごとの文字を次の場所に置く。

```
~/Library/Application Support/talk-catcher/transcripts/<録音ID>/0001.txt
```

- 録音ID は録音の始まりの時刻(例: `2026-11-13T10-00-00`)。録音が切れると同じ名前の m4a が `recordings/` にできる
- 1行目は録音の頭から数えた範囲(例: `[00:00:50-00:02:00]`)。2行目からが文字
- 2つ目からの区切りは、前の区切りの終わり(既定で10秒)と重なっている
- 声の無い区切りは置かない。番号は詰めて振る

会議の頭に Claude Code で次を打つ。`<書き出し先>` は Notion のページの URL などに置き換える。

```
/loop 1m talk-catcher の transcripts フォルダで一番新しい録音のフォルダを見て、まだ読んでいない .txt を番号順に読む。前の .txt の終わりと重なっている文は捨てる。会議の決定・宿題(誰が・いつまでに)・論点を、<書き出し先> の議事録に追記する。もう書いた内容は繰り返さない。どこまで読んだかは、議事録の末尾に「読んだ: 0003.txt」の形で残す
```
